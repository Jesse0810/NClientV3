# 漫画列表快捷列数

列表顶部新增网格按钮，点击“每行显示几本漫画”可选择 1～8 列，确认后立即调整。横屏、竖屏分别记忆，重新打开应用后继续使用保存的设置；默认仍为竖屏 2 列、横屏 4 列。

| 快捷入口 | 共用的已有设置 |
| --- | --- |
| 首页、搜索、筛选、书签结果、在线收藏 | 主界面横／竖屏列数 |
| 收藏漫画 | 收藏横／竖屏列数 |
| 历史记录 | 历史横／竖屏列数 |
| 下载漫画 | 下载横／竖屏列数 |

设置页已有的列表列数上限也扩大到 8，入口与设置页使用同一套键值。状态列表的原有设置同样支持 1～8 列。

## 行为

- 只有上述漫画列表显式启用新入口，使用独立的 `list_columns` 菜单 ID。漫画详情的分页预览仍使用原来的 `change_view` 和独立列数设置，评论布局保持原有行为。
- 确认仅保存当前列表、当前方向的一个偏好，并同步内存缓存，不重载无关设置。取消不写入；旋转或销毁界面时关闭旧选择弹窗。
- 列数变化时复用原布局管理器和数据适配器，保存首个可见条目的位置与顶部偏移，避免回到列表开头。空数据、尚无可见项或数据量缩短时安全处理。
- 不重建搜索框或菜单，保留已有关键词、筛选、分页及当前数据。布局增大可视范围后，无限滚动继续按原规则加载。
- 下载列表在单列与多列间采用不同视图类型，防止复用错误的横排／网格布局；适配器及选中记录保留。多选操作期间隐藏列数入口。

## 验证

- Base／Global 实际方法通过 1,276 条 JVM 断言，覆盖十个设置键的独立保存、缓存与重启恢复、非法值夹取、横竖屏切换、取消、滚动锚点和适配器复用。
- 下载列表实际方法通过 976 条断言，覆盖单列／多列视图类型、延迟创建视图、稳定 ID 选择保留和多选菜单。
- 菜单、四类列表入口、1～8 设置范围及中英文资源接线核对通过。
- Android 9+、Android 8 两个 Debug APK 构建通过。
- 上述逻辑检查使用轻量 Android 控件、偏好及布局管理器桩。当前未连接 Android 设备，SDK 未安装模拟器，未进行平板真机渲染验证。
