# NClientV3 4.2.15 简体中文预览版 3

- 修复搜索和书签编辑中，点「内容标签」等字段时筛选页初始化崩溃、界面退回首页的问题。内容标签、画师、角色、原作和社团可打开各自的筛选页。

Android 9 及以上请选择 `NClientV3_v4.2.15-zh-preview.3_android9plus_debug.apk`。Android 8.0／8.1 请选择 `NClientV3_v4.2.15-zh-preview.3_android8_debug.apk`。

此预览版安装为 **NClientV3 Debug**，可与正式版并存。若 Android 提示与旧 Debug 版签名冲突，请先导出数据并确认备份 ZIP 能解压，把已下载漫画另存到应用目录之外，再卸载旧 Debug、安装新包并导入数据。API Key 需在新安装中重新配置。
