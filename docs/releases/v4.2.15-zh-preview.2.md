# NClientV3 4.2.15 简体中文预览版 2

- 搜索与书签编辑共用高级筛选面板。内容标签、画师、角色、原作和社团有各自的可搜索候选页，支持按译名搜索。语言和类别可在主表单直接点选，新建书签默认包含中文。
- 候选标签随屏幕宽度换行，一行可以显示多个标签。标签右侧显示已知的作品数，单击依次切换包含、排除和不选。绿色表示包含，红色表示排除，点「应用」保存本次选择。
- 新增上传时间快捷选项和最少收藏数筛选。普通搜索支持页数范围，旧书签已有的页数条件会随书签保留。
- 改善备份 ZIP 的导出完整性和旧格式导入兼容性。导入时会识别损坏或不完整的备份，并显示具体提示。

Android 9 及以上请选择 `NClientV3_v4.2.15-zh-preview.2_android9plus_debug.apk`。Android 8.0／8.1 请选择 `NClientV3_v4.2.15-zh-preview.2_android8_debug.apk`。

此预览版安装为 **NClientV3 Debug**，可与正式版并存。若 Android 提示与旧 Debug 版签名冲突，请先从旧版导出数据，并将已下载漫画另行备份到应用目录之外。确认备份后再卸载旧 Debug、安装新包并导入数据。API Key 需在新安装中重新配置。
