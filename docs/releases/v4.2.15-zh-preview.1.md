# NClientV3 4.2.15 简体中文预览版 1

- 搜索、书签新增和书签编辑共用独立筛选页。打开字段即可浏览候选，支持输入单字搜索、多选、查看已选及清空。点「应用」提交，返回可取消。
- 包含值用绿底和勾号，排除值用红底和叉号，沿用「查看书签条件」的配色。标签右侧显示已知的单标签作品数。组合筛选的命中数以搜索结果为准。
- 从「管理书签」新建空白书签时默认包含中文，可取消。编辑既有书签时恢复保存的语言条件。
- 「检查更新」默认查正式版，开启「包含预览版更新」后也可查预览版。新预览包包含完整编号，应用可以比较预览版本和正式版本，按系统选择 APK，并打开对应发布页。

Android 9 及以上请选择 `NClientV3_v4.2.15-zh-preview.1_android9plus_debug.apk`。Android 8.0／8.1 请选择 `NClientV3_v4.2.15-zh-preview.1_android8_debug.apk`。两个包均适用于 64 位系统。

此预览版安装为 **NClientV3 Debug**，可与正式版并存。若旧 Debug 版的签名不同，请先从旧版导出数据并将漫画文件另行备份到应用目录以外，再卸载旧 Debug、安装新包并导入数据。API Key 需在新安装中重新配置。

构建流程核验两种 APK 的版本、系统要求、签名、独立筛选页资源和翻译数据。已运行书签、标签及更新检查回归。真机交互待试用验证。
