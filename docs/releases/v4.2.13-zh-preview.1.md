# NClientV3 4.2.13 名称翻译与列表列数测试版

## 本次更新

- **原作、角色采用简体中文名称**：新增原作 1,845 项、角色 6,724 项显示映射，主要覆盖日本作品，也采用已有可靠中文原名及部分可靠韩作译名。
- **画师、社团定位日文原名**：新增画师 10,396 项、社团 6,489 项显示映射，保留日文字形，不做简繁转换。
- **显示与搜索共用名称表**：简体中文界面的详情、搜索下拉框、管理标签及书签条件均使用新名称，支持按显示名搜索。英文界面、原始标签 ID、筛选值及书签查询保持原有口径。
- **来源不明及欧美项保留原文**：四字段共 81,162 个不同原值，本次采用 25,454 个映射，其余 55,708 项保留原文，包含欧美、混源、同名身份冲突及缺少可靠名称的情况。逐项来源和未采用原因见[完整名称记录](https://github.com/Jesse0810/NClientV3/blob/v4.2.13-zh-preview.1/data/entity-translations/README.md)。内容标签继续沿用原有 1,127 项批准名单政策。
- **漫画列表新增列数按钮**：点击顶部网格按钮，可选择每行显示 1～8 本漫画。首页、搜索／筛选、书签结果、在线收藏、本地收藏、历史及下载列表均可使用；横竖屏分别记忆，切换时保留浏览位置。默认仍为竖屏 2 列、横屏 4 列。
- **下载列表单列／多列切换**：同步切换对应卡片布局，保留数据和选中记录，多选操作期间隐藏列数入口。漫画详情的预览列数仍单独设置。

## 从旧 Debug 测试版更新

CI 使用临时 Debug 签名，新包可能无法直接覆盖旧测试版。**先备份并确认文件可用，再考虑卸载旧版。**

1. 在旧版“设置 → 导出数据”，将 ZIP 保存到系统下载目录等应用目录之外的位置。
2. ZIP 包含书签、数据库记录及设置，**不包含 API Key 和下载的漫画图片**。API Key 应从网站账户设置重新取得；需要保留的漫画文件请另行复制到应用目录之外。
3. 若安装提示签名不匹配，在完成备份后卸载旧测试版、安装新版，再通过“设置 → 导入数据”恢复，完成后重启应用。

本版本为测试版。应用内检查更新仍指向上游，请通过本仓库 Releases 下载。
