# NClientV3 4.2.8 简体中文预览版 1

这是包含最新简体中文界面、内容标签翻译和搜索改进的 **Debug 测试版**。

## 下载与安装

| 附件 | 适用系统 |
| --- | --- |
| `NClientV3_v4.2.8-zh-preview.1_android9plus_debug.apk` | **Android 9 及以上，推荐下载** |
| `NClientV3_v4.2.8-zh-preview.1_android8_debug.apk` | Android 8.0 / 8.1 兼容版 |
| `SHA256SUMS.txt` | 两个 APK 的 SHA-256 校验值 |

应用名称为 **NClientV3 Debug**，包名为 `com.maxwai.nclientv3.debug`，可与正式版并存；这是独立测试应用，不是正式版的覆盖升级包，也不会自动继承正式版的应用数据。两个 APK 是同一测试应用的不同系统兼容版本，选择一个安装即可。

已有其他签名的 Debug 测试版时，需要先备份数据并卸载旧测试版；正式版不需要卸载。

## 本次更新

- 简体中文界面将“标签”明确为“内容标签”，将 Artists 显示为“画师”，将 Online Tags 显示为“在线黑名单标签”。
- 为语言与类别值提供简体中文名称，例如“日语”“英语”“中文”“同人志”“商业志”。
- 内容标签管理固定为 1,127 个原始名称，含 781 个显示映射；其余标签在详情页完整显示原文。
- 将 `incest` 显示为“近亲乱伦”；没有可靠译名的保留项继续显示原文。
- 简体中文“内容标签”管理页按实际显示名搜索，例如输入“近亲”可找到“近亲乱伦”。
- 修复切换页签、调整最小数量及连续输入时的搜索状态问题。
- 翻译仅用于显示与匹配，提交搜索和保存数据时保留原始标签名称与 ID。

此版本用于体验和反馈，采用 Debug 签名。应用内更新检查仍指向上游项目；请通过本仓库的 Releases 页面下载本预览版。

两个 APK 在发布前均验证签名、包名、最低 Android 版本及内嵌标签资源。可使用 `SHA256SUMS.txt` 核对下载文件的完整性。
