# NClientV3 4.2.12 搜索与书签优化测试版

## 本次更新

- **搜索页直接展示完整条件**：移除顶部展开条件的“＋”开关，搜索框固定在顶部，条件和历史记录可滚动浏览。
- **原作、角色、画师、社团改用下拉选择**：移除未选择的预置推荐项；添加时可按关键词搜索全部已有值，必须选中列表项才能添加，不能创建任意名称。已有筛选和旧书签条件继续保留，类别与语言的选择规则不变。
- **简化选项文字**：有译名时只显示译名，不再附加括号原值。上述四类专名目前没有专门译表，继续保留原文；搜索和保存仍使用原始标签值。
- **修复重复类别**：合并原名相同的重复“其他”选项，保留原有选择状态；不改动漫画关联和原始标签 ID。
- **书签不保存排序**：每次打开从第一页按最新排序展示，结果页可临时调整排序，且不改动全局排序设置。新建、编辑和条件展示移除排序信息，旧书签继续兼容。
- **调整书签列表按钮**：“查看条件”移到右侧，与编辑、删除按钮并排。
- **修复打开浏览器**：把应用内部 API 地址转换为网站页面地址，正确传入筛选、分页和当前排序；没有可用浏览器时显示提示。

## 从旧 Debug 测试版更新

CI 使用临时 Debug 签名，新包可能无法直接覆盖旧测试版。**先备份并确认文件可用，再考虑卸载旧版。**

1. 在旧版“设置 → 导出数据”，将 ZIP 保存到系统下载目录等应用目录之外的位置。
2. ZIP 包含书签、数据库记录及设置，**不包含 API Key 和下载的漫画图片**。API Key 应从网站账户设置重新取得；需要保留的漫画文件请另行复制到应用目录之外。
3. 若安装提示签名不匹配，在完成备份后卸载旧测试版、安装新版，再通过“设置 → 导入数据”恢复，完成后重启应用。

本版本为测试版。应用内检查更新仍指向上游，请通过本仓库 Releases 下载。
