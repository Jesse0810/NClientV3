# NClientV3 4.2.14 搜索与标签整理测试版

## 本次更新

- **输入一个字即可提示标签**：搜索页和新建／编辑书签时，输入“群”“近”等单字即可匹配下拉选项，无需输入完整名称。五个标签字段共用可搜索的已有值选择器。
- **搜索页增加独立“搜索”按钮**：无需输入关键字也能提交筛选条件；顶部输入框明确提示“输入搜索关键字（可选）”。移除内容标签的预设推荐项及对应的推荐数量设置。
- **内容标签按含义处理重名**：将拼写错误及确认同义的 7 组标签合并展示；将不同含义的重名标签分别命名，例如“群交／乱交聚会”“水下场景／水下性行为”“全身纹身／大面积纹身”。原有 1,127 个批准原值保留，合并后展示为 1,118 个内容标签选项。
- **保留旧拼写查询入口**：默认选择标准拼写；点击“查询旧拼写”可单独选择 9 个旧拼写值。网站不支持已验证可用的多标签任一匹配查询，因此标准拼写搜索不会自动合并旧拼写独有的结果，旧书签中的明确旧拼写条件继续保留。
- **合并标签偏好与排除行为**：同组标签的本地偏好和在线黑名单操作同步处理原始标签；排除条件涵盖同组拼写，详情页合并重复展示，保留原始标签数据。
- **原作、角色、画师、社团重名可区分**：全量核查后，对这四个字段的 136 组重名、273 个原值补充括号原名，搜索选项、详情及书签条件使用一致的显示名称。
- **完善翻译记录与自动检查**：记录每项内容标签的改名依据、旧译名、来源及合并关系，并输出五个字段的全量重名核查清单。

逐项记录：[内容标签复核](https://github.com/Jesse0810/NClientV3/tree/v4.2.14-zh-preview.1/data/tag-translations/content-label-review)、[五字段重名清单](https://github.com/Jesse0810/NClientV3/tree/v4.2.14-zh-preview.1/data/translation-collisions)。

## 从旧 Debug 测试版更新

CI 使用临时 Debug 签名，新包可能无法直接覆盖旧测试版。**先备份并确认文件可用，再考虑卸载旧版。**

1. 在旧版“设置 → 导出数据”，将 ZIP 保存到系统下载目录等应用目录之外的位置。
2. ZIP 包含书签、数据库记录及设置，**不包含 API Key 和下载的漫画图片**。API Key 应从网站账户设置重新取得；需要保留的漫画文件请另行复制到应用目录之外。
3. 若安装提示签名不匹配，在完成备份后卸载旧测试版、安装新版，再通过“设置 → 导入数据”恢复，完成后重启应用。

本版本为测试版。应用内检查更新仍指向上游，请通过本仓库 Releases 下载。
