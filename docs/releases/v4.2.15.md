# NClientV3 4.2.15 简体中文正式版

- 搜索和书签编辑共用高级筛选。内容标签、画师、角色、原作和社团各有独立候选页，支持按译名搜索。候选随屏幕宽度多列排列，并显示已知的作品数。
- 点同一个标签依次切换「包含 → 排除 → 不选」，绿底表示包含，红底表示排除。修复了打开独立筛选页时可能退回首页的问题。
- 语言和类别可直接点选。新建书签默认包含中文。新增上传时间快捷选项和最少收藏数筛选，旧书签已有的页数条件会保留。
- 改善备份 ZIP 的导出完整性和旧格式导入兼容性，导入损坏或不完整的文件时会显示具体提示。
- 检查更新默认查本仓库正式版。开启「包含预览版更新」后，也可查看预览版。

## 下载与安装

| 附件 | 系统 |
| --- | --- |
| `NClientV3_v4.2.15_android9plus.apk` | Android 9 及以上 |
| `NClientV3_v4.2.15_android8.apk` | Android 8.0／8.1 |
| `SHA256SUMS.txt` | 下载完整性校验 |

本版沿用 `v4.2.14` 的正式签名，从该正式版更新可直接覆盖安装。正式版与 **NClientV3 Debug** 可并存。若在 Debug 版试用，请先导出数据，再安装正式版并导入备份。API Key 需在正式版重新配置，已下载漫画请另行备份。
