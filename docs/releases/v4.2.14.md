# NClientV3 4.2.14 简体中文正式版

本版基于已验证功能的 4.2.14 测试版构建，使用固定正式签名，关闭调试并启用 Release 优化。之后本仓库的正式版沿用相同签名，可以直接覆盖更新。

## 主要功能

- 简体中文内容标签，以及原作、角色、画师、社团名称显示和搜索。
- 搜索页完整筛选条件、独立搜索按钮和可选关键字提示；搜索与书签编辑支持输入单字匹配标签。
- 内容标签按含义区分重名；确认的同义或拼写错误标签合并展示，并保留旧拼写查询入口。
- 书签支持自定义名称、新增、编辑和按字段查看条件；结果分页和排序独立设置。
- 漫画列表可调整每行 1～8 本，横竖屏分别记忆，适用于手机和平板。
- 应用内检查更新改为本仓库正式版，按 Android 系统版本选择正确的 APK。

内容标签继续使用 1,127 个批准原值，合并后为 1,118 个选项。普通选择默认查询标准拼写；需要查询旧拼写独有结果时，可使用“查询旧拼写”。逐项依据见[内容标签复核记录](https://github.com/Jesse0810/NClientV3/tree/v4.2.14/data/tag-translations/content-label-review)和[重名核查清单](https://github.com/Jesse0810/NClientV3/tree/v4.2.14/data/translation-collisions)。

## 下载

| 附件 | 系统 |
| --- | --- |
| `NClientV3_v4.2.14_android9plus.apk` | Android 9 及以上，推荐 |
| `NClientV3_v4.2.14_android8.apk` | Android 8.0 / 8.1 |
| `SHA256SUMS.txt` | 下载完整性校验 |

两个 APK 均支持 64 位 Android 系统。应用名称为 **NClientV3**，包名为 `com.maxwai.nclientv3`，与 `NClientV3 Debug` 测试版属于两个应用。

## 从 Debug 测试版迁移

1. 在测试版“设置 → 导出数据”，将 ZIP 保存到系统下载目录等应用目录之外的位置。
2. 安装本正式版，通过“设置 → 导入数据”恢复书签、数据库记录及设置，完成后重启应用。
3. 导出的 ZIP **不包含 API Key 和下载的漫画图片**。请在正式版重新配置 API Key，需要保留的漫画图片另行复制或迁移。
4. 确认正式版数据和文件完整后，再决定是否卸载测试版。

## 验证与签名

构建包含 Android 9+ 和 Android 8 两种 Release 包，检查正式包名、非调试标记、版本、最低系统要求、内嵌翻译数据、单字下拉提示配置、签名证书及附件 SHA-256。书签、标签合并、名称记录和更新包选择运行自动回归检查。

公开签名证书及 SHA-256 指纹记录在 [config](https://github.com/Jesse0810/NClientV3/tree/v4.2.14/config)。正式签名私钥不包含在源代码或发布附件中。
