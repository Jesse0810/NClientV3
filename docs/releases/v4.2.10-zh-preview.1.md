# NClientV3 4.2.10 书签管理测试版

## 本次更新

- **管理页直接新增**：在“管理书签”右上角点击“＋”，填写名称及关键词、包含/排除标签、漫画页数范围、上传时间范围、排序后即可保存，无须先运行搜索。新表单为空白全站范围，不自动带入全局筛选。
- **取消结果分页保存**：书签列表不再显示浏览页码，新旧书签每次打开均从第一页开始。漫画本身的页数范围仍保留为筛选条件。
- **收紧加入书签入口**：全站结果存在实际筛选条件时才提供入口；在线收藏、无筛选首页及仅切换排序的场景不再支持新增。管理标签或语言设置实际形成的筛选仍可保存。
- **忽略分页查重**：从不同结果页保存相同 URL 条件组合不会重复新建，历史上分别命名的旧记录保留。
- 保留 4.2.9 的自定义名称、筛选条件译名、编辑功能、复杂表达式及旧备份兼容。

## 从旧 Debug 测试版更新

CI 使用临时 Debug 签名，新包可能无法直接覆盖旧测试版。**先备份，确认备份可用后再考虑卸载旧版。**

1. 在旧版“设置 → 导出数据”，将 ZIP 保存到系统下载目录等应用目录之外的位置，并确认文件存在。
2. ZIP 包含书签、数据库记录及设置，**不包含 API Key 和下载的漫画图片**。API Key 应从网站账户设置重新取得；需要保留的漫画文件请另行复制到应用目录之外。
3. 若安装提示签名不匹配，在完成备份后卸载旧测试版、安装新版，再通过“设置 → 导入数据”恢复，完成后重启应用。

本版本为测试版。应用内检查更新仍指向上游，请通过本仓库 Releases 下载。
