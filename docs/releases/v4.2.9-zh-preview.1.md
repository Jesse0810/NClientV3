# NClientV3 4.2.9 书签编辑测试版

## 本次更新

- **添加时命名**：点击“加入书签”后可输入自定义名称，保存前会显示本地化的条件摘要。
- **书签条件显示译名**：列表显示名称、条件、排序和保存页码。内容标签沿用已批准词库，语言和类别也显示对应译名；无译名的项保留原文。
- **编辑书签**：在“管理书签”点击铅笔按钮，可修改名称、关键词、包含/排除标签、页数、上传时间和排序。
- 只改名称时保留原始条件与页码；修改条件后从第一页打开。取消编辑不会修改原书签。
- 旧书签的数据保留，尚未设置名称的项显示“未命名书签”。打开书签使用当时保存的完整条件，不再混入当前全局筛选或语言设置。
- 自定义复杂表达式完整保留在关键词栏，已知标签在摘要中按显示译名展示。

## 从先前的 Debug 测试版保留数据

先前的 CI 测试包使用临时 Debug 签名，新的构建不保证可以直接覆盖安装。**不要先卸载旧版。**

1. 在旧版打开“设置 → 导出数据”，将备份 ZIP 保存到系统下载目录或其他应用目录之外的位置，确认提示导出完成且文件确实存在。
2. 数据 ZIP 包含书签、数据库记录和设置，**不包含下载的漫画图片文件**；需要保留的下载文件应另行复制到应用目录之外。
3. 如果安装新版时提示签名不匹配，在确认备份后再卸载旧测试版并安装新版。
4. 在新版“设置 → 导入数据”中选择备份，导入完成后重启应用。旧书签名称初始为空，可在管理书签中命名和编辑。

本版本采用 Debug 签名，应用内检查更新仍指向上游；请通过本仓库 Releases 页面下载。
