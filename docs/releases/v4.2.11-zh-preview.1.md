# NClientV3 4.2.11 标签偏好与书签界面测试版

## 本次更新

- **修复清除标签偏好**：“已应用筛选”页清除所有本地包含/排除偏好，分类页只清除该分类，完成后重新加载列表及勾选状态。在线黑名单单独管理，不再显示本地偏好清除入口。
- **后台更新保留当前偏好**：更新标签名称、分类和计数时保留当前偏好及在线标记，避免重新写入清除前的旧状态。
- **两行书签列表**：仅显示名称和“查看条件”，移除省略的条件摘要，编辑与删除按钮横排。
- **条件弹窗分组**：沿用详情页字段布局及译名，包含值使用勾号和绿色背景，排除值使用叉号和红色背景，适配深色模式。长值完整换行，复杂表达式保留逻辑关系并使用中性高亮。
- **简化新建和编辑书签**：移除“页面范围”输入和固定“搜索范围：全站”说明；已有页数条件及历史收藏范围保持兼容。
- **简化书签结果页**：从书签打开后隐藏搜索按钮及“加入书签”选项，翻页、排序或刷新后继续隐藏。

## 从旧 Debug 测试版更新

CI 使用临时 Debug 签名，新包可能无法直接覆盖旧测试版。**先备份并确认文件可用，再考虑卸载旧版。**

1. 在旧版“设置 → 导出数据”，将 ZIP 保存到系统下载目录等应用目录之外的位置。
2. ZIP 包含书签、数据库记录及设置，**不包含 API Key 和下载的漫画图片**。API Key 应从网站账户设置重新取得；需要保留的漫画文件请另行复制到应用目录之外。
3. 若安装提示签名不匹配，在完成备份后卸载旧测试版、安装新版，再通过“设置 → 导入数据”恢复，完成后重启应用。

本版本为测试版。应用内检查更新仍指向上游，请通过本仓库 Releases 下载。
