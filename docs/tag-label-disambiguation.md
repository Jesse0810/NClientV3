# 内容标签语义合并与同名区分

内容标签逐项审查含义：拼写错误／明确同义写法合并展示，概念不同的原值使用不同中文名称。其他四个字段仍仅在重名时追加原文。

## 内容标签

- 7 组合并收拢 9 个别名：单一女性、自慰、变身、总集篇、触手、第三方水印、系列作。
- 8 组区分译名，包括“群交／乱交聚会”“全身纹身／大面积纹身”“扫描组水印／第三方水印”等；具体原值、理由和证据见[逐项语义复核](../data/tag-translations/content-label-review/README.md)。
- 1127 个批准原值及其 ID 不删，主选择器／管理列表按 1118 个概念展示。详情合并重复概念，保留原始漫画关联。管理页修改一个合并概念的偏好会同步所有成员；旧冲突状态以排除优先，出现次数取成员最大值，不将可能重叠的计数简单相加。
- 内容标签的原文词典快照不变，31 项人工复核覆盖记录单独标注为 AI，并保留旧译名、旧来源和证据。应用映射仍是 781 项，其余 346 个批准原值保留原文。

## 查询与旧拼写

实际网站查询未支持测试过的 OR／竖线并集写法，且存在仅带旧拼写的漫画。按用户明确选择：默认搜索正确拼写，在内容标签弹窗中保留“查询旧拼写”入口。旧值只在这个入口和明确引用它的筛选条件中附加“旧拼写”提示。

选择器始终绑定具体原值、字段和 ID，确认前再次验证。选择同一概念的标准写法或旧拼写时会替换对应旧条件，避免同时要求两种拼写；键盘确认使用相同校验，手输中文不能创建临时标签。旧书签中的明确旧拼写查询不自动改写。

排除合并概念时，执行查询展开为所有成员的负条件。新书签仍保存未展开的逻辑条件，保持可编辑；分页、排序、打开浏览器使用实际执行查询。网站查询能力证据见[实测记录](../data/tag-translations/content-label-review/network-evidence.json)。

## 原作、角色、画师、社团

其他四字段共有 136 组重名、273 个原值，继续以“显示名（原文）”区分。规则应用于下拉选项、已选条件、管理标签、详情和书签。未重名项维持原有显示，英文界面保留原文。

## 持续检查

运行 `python3 scripts/check_content_label_review.py` 核验语义决定、映射、来源与生成的别名表；运行 `python3 scripts/check_translation_collisions.py --check` 核验原值和逻辑概念两种口径的重名，以及运行时索引。CI 和发布构建均执行检查，定期库存更新会重新生成重名审计。

`python3 scripts/check_content_aliases.py` 是持久回归检查：编译实际别名表、合并／排除辅助类、查询解析器和标签集合，验证旧拼写正向查询保留、整组排除、同原名多 ID 等情况，当前 205 项断言通过。

完整记录见[重名清单](../data/translation-collisions/README.md)。已确认的内容别名不当作需要括号的冲突；真正不同的内容概念当前无重名。
